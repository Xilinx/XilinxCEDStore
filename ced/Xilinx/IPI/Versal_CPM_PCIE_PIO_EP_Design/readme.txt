##############################################################################
		CPM - PCIe PIO Example Design
##############################################################################
This package contains the CPM - PCIe PIO Example Design. It covers both CPM4
and CPM5; CPM4 PIO design is generated if VCK190 is selected and CPM5 PIO
design is generated if VPK120 is selected. Please use below version of tool
to generate the design

Vivado Version  - 2026.2

- Open Vivado and click on "Open Example Project"
- Select "Versal CPM PCIE PIO EP Design" template and select the board
- Click on Generate Device Image under Flow Navigator to generate the PDI

NOTE :
1. This design is provided for hardware test flow. Simulation is not supported

##############################################################################
		PL - QDMA Root Port Example Design
##############################################################################
This package contains the Versal PL QDMA Root Port Example Design. It allows
generating PL QDMA RP design for VCK190 and VPK120 respectively based on the
board selected. Please use below version of tool to generate the design

Vivado Version  - 2026.2

- Open Vivado and click on "Open Example Project"
- Select "Versal PL QDMA RP Design" template and select the board
- Click on Generate Device Image under Flow Navigator to generate the PDI

The associated drivers can be downloaded from:
  https://github.com/Xilinx/dma_ip_drivers

NOTE :
1. This design is provided for hardware test flow. Simulation is not supported

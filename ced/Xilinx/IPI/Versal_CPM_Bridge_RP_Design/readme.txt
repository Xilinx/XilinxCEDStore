##############################################################################
		CPM - Bridge Root Port Example Design
##############################################################################
This package contains the CPM - Bridge Root Port Example Design. It allows
generating CPM4 and CPM5 versions for VCK190 and VPK120 respectively based on
the board selected. Please use below version of tool to generate the design

Vivado Version  - 2026.2

- Open Vivado and click on "Open Example Project"
- Select "Versal CPM Bridge RP Design" template and select the board
- Click on Generate Device Image under Flow Navigator to generate the PDI

NOTE :
1. This design is provided for hardware test flow. Simulation is not supported
